# 🏛️ Saudi Wonders

**Saudi Wonders** is a Flutter mobile application designed to explore the rich heritage and historical landmarks of Saudi Arabia 🇸🇦. The app combines a modern "Desert Luxury" visual aesthetic with a seamless mobile exploration experience.

## ✨ Features

- **🏜️ Desert Luxury Aesthetic:** A dark-themed UI (`#121212`) featuring warm desert brown accents (`#C87D55`) and ambient lighting effects.
- **🖼️ Heritage Visuals & Glassmorphism:** Atmospheric blur effects (`BackdropFilter`) and customized gradient overlays for place cards.
- **📜 Place Exploration:** A curated list showcasing historical and cultural sites across Saudi Arabia.
- **🔍 Detailed Landmark View:** High-quality imagery, star ratings ⭐️, ratings count, and detailed historical overviews.
- **🔖 Favorites System:** Bookmark favorite historical places for quick access later.
- **🌐 Dynamic Data Fetching:** Connected to a REST API via `http` package to dynamically display heritage content.

---

## 🛠️ Tech Stack

- **Framework:** [Flutter](https://flutter.dev/) (Dart)
- **UI/UX Components:** Glassmorphism (`BackdropFilter`), Custom Gradients, Floating Cards
- **State Management:** `StatefulWidget`
- **Network & API:** `http` package for REST API calls
- **Storage:** Local persistence manager for saved places
